# 去哪遛 · 宠物友好地点与宠物好友 Web Demo

产品从「去哪遛」出发：选择适合宠物的公园或公共空间，看到宠物好友主动共享的本次遛弯地点，自行前往；在相遇后建立好友关系，下次可以偶遇，也可以提前约遛。

## 运行

```sh
npm install
npm run dev
```

构建：`npm run build`。类型检查：`npx tsc --noEmit`。业务代码检查：`npx oxlint app`。核心状态规则：`node --test app/walk-model.test.mjs`。

生成器附带组件有既有 lint 报告，业务代码单独检查，不修改第三方组件来消除它们。

## 信息架构

- **遛宠地图（默认首页）**：地点搜索，好友在遛、安静一点、收藏、地点类型筛选；地点设施与牵绳提醒；宠物好友的公共地点；前往与开始遛弯。
- **我的宠物**：宠物档案、好友数、出门记录、陪伴时长、照护打卡。
- **宠物好友**：正在遛、所有好友、申请；以宠物身份建立双方确认的好友关系；看地点、自行过去、约下次、聊天。
- **宠友圈**：好友日常、自己的日常与收藏。单列近况，不再承担首页发现任务。
- **陪伴日历**：按月、按天回看已结束的遛弯，另列照护记录和约遛。

## 重点演示路径

1. 首页看到豆包、曲奇正在「望京宠友草坪」→ 选择地点 → 就去这里 → 查看演示路线 → 已到达，开始遛弯。
2. 开始时默认「仅自己可见」；主动开启「让宠物好友看见我们」才共享本次公共地点。
3. 遛弯中切换隐身，或点击「遛好啦，回家」；结束记录进入陪伴日历，地点共享关闭。设定时间到期也会自动结束。
4. 地点详情 → 认识常来这里的土豆 → 申请宠物好友 → 模拟对方接受 → 查看好友主动共享的遛弯地点。
5. 好友 → 约下次 → 选择地点和时间 → 模拟接受、婉拒或取消。

查看地点和路线不会发送消息、生成邀请或启动共享。

## 演示边界

地图、路线、地点设施、距离、宠物资料及好友在线状态为预置演示，不提供实际导航，不请求 GPS，不发送真实通知。照片来自 Unsplash CDN。

演示好友共享状态设有截止时间，刷新页面不会自动续期；到期后可在「演示说明」中重新模拟好友出门。

所有修改仅保存到当前浏览器的 `qunaliu-walk-demo-v2`。首次升级会读取并保留旧 `qunaliu-demo-v1` 的宠物档案、动态、点赞、评论、收藏、聊天、邀请和照护记录；旧键不删除。原先的「关注」不自动转成双向好友关系。

正式产品还需接入真实地图、账号与好友权限、服务端会话和共享过期机制。前端演示中的可见性过滤不是线上安全边界。

## 验证

运行类型检查、业务代码静态检查、HTTP 页面响应和生产构建。状态测试覆盖：双向好友限制、未共享/已结束/已过期/尚未开始的状态隐藏、结束幂等性、记录时长封顶、好友地点筛选随共享失效。未执行浏览器自动化交互测试。

## 北京版更新

演示场景统一为北京朝阳望京，旧版本本地数据中的系统预置动态城市会迁移，用户自己的记录保留。

- 地图「补充一个遛宠好去处」→ 填写地址、类型、现场环境、体验及照片 → 保存后在地图显示，标记“待核实”，自动收藏。数据仅在当前浏览器，未提交真实审核。
- 遛弯结束立即停止共享 → 可选照片、我与 TA 的心情、实际遇见的好友、文字 → 保存至私人陪伴日历。可以跳过，之后从历史记录补记，也可反复编辑。
- 日历按日期展示记忆卡；已记录相遇次数关联到宠物好友卡。仅同时在线或同处一个地点，不会自动记为相遇。
- 照片只支持 1 MB 内的 JPG/PNG/WebP。浏览器存储空间不足会显示提示；未接入云存储。
