# 去哪遛 · 手机 H5 宠物出行产品

通过浏览器演示手机 App 的操作体验。桌面也以 430px 手机宽度呈现；手机全宽。核心链路：找到适合遛宠的地点 → 看宠物朋友 → 出门 → 留下相遇与陪伴记录。

## 当前交付状态

已完成手机布局、高德 JS API 2.0 接入代码、搜索北京 POI、用户主动定位、步行路线规划、高德导航链接、真实地点收藏及现场体验补充。**地图尚未配置项目 Key，因此未完成真实服务联调。** 无 Key 时显示待启用状态，取消旧的手绘示意地图。

见 [MAP-SETUP.md](MAP-SETUP.md) 配置地图。地图 Key 是 Web 端（JS API）类型，安全密钥保留在 Worker，不发给浏览器。

宠物好友、好友共享、聊天和邀请仍为当前浏览器的交互模拟，尚无跨用户实时同步。示例好友地点明确标注，不映射到真实坐标。不能把此版本作为完整线上社交产品。

## 功能

- 遛宠地图：首页，真实地图搜索、主动定位、步行路线、外部导航、收藏。POI 收录不代表宠物友好，现场携宠规则单独待核实。
- 我的宠物：资料、好友数、出门记录、陪伴时长与照护记录。
- 宠物好友：模拟好友列表、双方确认申请、约下次与聊天。
- 宠友圈：单列的好友日常、个人日常与收藏。
- 陪伴日历：出门回忆、照片、主人及宠物的心情、手动记录实际遇见的朋友。结束遛弯先关闭共享，再填写回忆。
- 地点贡献：绑定搜索选择的真实 POI 坐标，补充入口、环境、携宠要求和照片。本地保存并标为待核实。

## 本地开发

```sh
npm install
npm run dev
```

按 `.env.example` 配置忽略提交的 `.env`，线上通过 Sites 同名环境变量配置。生产构建 `npm run build`。类型检查 `npx tsc --noEmit`。业务静态检查 `npx oxlint app lib/amap-client.ts lib/amap-service.ts`。测试 `node --test app/walk-model.test.mjs lib/amap-service.test.mjs`。

生成器附带组件有既有 lint 报告，业务代码单独检查。按 Sites 环境约定，未进行浏览器自动化测试；真实高德功能必须在有效 Key 配置后完成联调。

## 数据边界

浏览器存储键 `qunaliu-walk-demo-v2`，兼容旧 `qunaliu-demo-v1` 的宠物档案、动态、点赞、评论、收藏、聊天、邀请和照护记录。不把原来的关注自动转换成双向好友。旧地点只保留为历史或社交演示记录，不会强行转换成真实经纬度。

主动共享以单次遛弯为单位，隐身、结束和到期停止。查看地点与路线不通知好友。地理定位只用于当前页面找路，不保存设备定位坐标到宠友共享状态。前端过滤不构成正式产品的服务端安全边界。

上传照片为 1 MB 内 JPG/PNG/WebP，本地保存。空间不足会提示。正式产品尚需账号、服务端好友与位置权限、实时状态、地点审核、媒体存储。
