# 碰爪 · 手机 H5 宠物出行产品

通过浏览器演示手机 App 的操作体验。桌面以 iPhone 15 Pro Max 的 430 × 932 逻辑画布等比呈现，含状态栏及 Home 安全区，屏幕内部滚动；手机全宽并使用系统安全区。核心链路：找到适合遛宠的地点 → 看宠物朋友 → 出门 → 留下相遇与陪伴记录。

![碰爪产品演示](docs/product/assets/pengzhua-demo-cover.png)

## 当前交付状态

已完成手机布局、高德 JS API 2.0 接入代码、搜索北京 POI、用户主动定位、导航方式演示弹框（暂不规划路线或跳转高德）、真实地点收藏及现场体验补充。已创建本项目高德 Web Key，配置线上域名白名单与服务端安全密钥。 无 Key 时显示待启用状态，取消旧的手绘示意地图。

见 [MAP-SETUP.md](MAP-SETUP.md) 配置地图。地图 Key 是 Web 端（JS API）类型，安全密钥保留在 Worker，不发给浏览器。

宠物好友、好友共享、聊天和邀请仍为当前浏览器的交互模拟，尚无跨用户实时同步。示例好友地点明确标注，不映射到真实坐标。不能把此版本作为完整线上社交产品。

## 首批北京宠物友好地点

地图默认进入“推荐”，内置4处：爪吧宠物乐园（温榆河示范区店）、老山城市休闲公园、狼垡城市森林公园宠物友好专区、CKC国际宠物公园。坐标与POI ID来自2026-09-05高德查询；携宠属性独立依据公开来源。每处包含准入范围、入口说明、费用条件、资料核对日期；原文链接保留在数据目录，不在地点页面呈现。资料核对不等于现场核验，不提供实时拥挤度或未经证实的犬种承诺。

本轮未获取可核验的小红书原帖，因此使用北京旅游网、首都文明网、政府页面和温榆河公园官方微博的公开内容，不标注为小红书提取。原文不整段搬运，不搬运用户照片。目录维护在 `app/beijing-places.ts`，按高德POI ID与收藏及搜索去重。

## 功能

- 遛宠地图：首页，真实地图搜索、主动定位、导航演示提示、收藏。POI 收录不代表宠物友好，现场携宠规则单独待核实。
- 我的宠物：资料、好友数、出门记录、陪伴时长与照护记录。
- 宠物好友：模拟好友列表、双方确认申请、约下次与聊天。
- 宠友圈：单列的好友日常、个人日常与收藏。
- 陪伴日历：出门回忆、照片、主人及宠物的心情、手动记录实际遇见的朋友。结束遛弯先关闭共享，再填写回忆。
- 地点贡献：绑定搜索选择的真实 POI 坐标，补充入口、环境、携宠要求和照片。本地保存并标为待核实。

## 本地开发

需要 Node.js 22.13.0 或更高版本及 npm。

```sh
git clone https://github.com/leo-ai-pm/pengzhua.git
cd pengzhua
npm ci
cp .env.example .env
npm run dev
```

打开终端显示的本地地址，默认是 `http://localhost:3000`。地图凭据留空时仍可体验本地宠物社交演示，真实地图会显示待启用；启用方式见 [地图配置](MAP-SETUP.md)。已有 `.env` 的开发者无需再次复制，避免覆盖自己的配置。

```sh
npm test             # 现有业务测试
npm run typecheck    # TypeScript 检查
npm run build        # 生产构建
npm start            # 在本机预览 Worker 构建产物
```

普通本地开发不需要 OpenAI Sites 账号。现有部署所有者可继续使用本地忽略提交的 `.openai/hosting.json`；其他开发者部署时应创建自己的站点与环境变量。

业务静态检查：`npx oxlint app lib/amap-client.ts lib/amap-service.ts`。

生成器附带组件有既有 lint 报告，业务代码单独检查。按 Sites 环境约定，未进行浏览器自动化测试；真实高德搜索与步行接口已返回有效数据；设备定位需用户在手机浏览器中授权。

## 数据边界

浏览器存储键 `qunaliu-walk-demo-v2`，兼容旧 `qunaliu-demo-v1` 的宠物档案、动态、点赞、评论、收藏、聊天、邀请和照护记录。不把原来的关注自动转换成双向好友。旧地点只保留为历史或社交演示记录，不会强行转换成真实经纬度。

主动共享以单次遛弯为单位，隐身、结束和到期停止。查看地点与路线不通知好友。地理定位只用于当前页面找路，不保存设备定位坐标到宠友共享状态。前端过滤不构成正式产品的服务端安全边界。

上传照片为 1 MB 内 JPG/PNG/WebP，本地保存。空间不足会提示。正式产品尚需账号、服务端好友与位置权限、实时状态、地点审核、媒体存储。

## 手机交互修订 v8

地点详情提供返回列表与展开/收起；“怎么走”可选择步行、驾车、骑行并确认演示提示，不请求路线或跳转。按 430 × 932 手机画布统一卡片、头像、帖子图片与控件尺寸。邀约卡片可查看日期、地点、邀约人和留言；帖子详情支持聊天与发起约遛。种子帖距离标为示例，新帖未共享位置时不编造距离。

## 陌生人联系 v9

宠友圈增加“同城散步”，可用土豆示例体验好友申请。陌生人先查看名片或提交简短介绍，待回应时不能重复申请、私聊或约遛；明确模拟对方接受后，才开放联系。豆包等原有好友保留邀约入口并显示关系。前端规则用于演示，正式版权限必须由服务端校验。

## 广场默认入口

宠友圈默认面向所有用户展示“广场”，混合好友与非好友的公开演示帖子。好友圈作为独立筛选保留。土豆、汤圆、芝麻默认不是好友，申请成功前不能私聊或约遛；用户已有好友关系和记录不重置。
