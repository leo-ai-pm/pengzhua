# 碰爪 · 高清手机框 PNG

共 37 张，导出日期：2026-09-05。来自现有[碰爪 Web Demo](https://qunaliu-pet-community.ljhsmart1.chatgpt.site/)，用于项目总览、PRD、页面说明和状态流文档。

- 每张均为 **1344 × 2850 像素、3 倍像素密度、PNG 无损格式**。手机内屏对应 430 × 932 逻辑尺寸，另保留黑色边框及细外轮廓。
- 手机框之外为透明背景，四个角的透明度均校验为 0；保留灵动岛、状态栏、底部横条和屏幕内全部可见内容。
- 图片直接由页面高像素密度渲染生成。弹窗背后的虚化是现有产品交互样式，前景界面与文字保持清晰。
- 以单张 PNG 原文件插入文档，避免复制浏览器里的缩略预览。文档编辑器若提供“原图/不压缩”，选择该选项。
- 本目录是本轮高清交付。上一级目录的旧裸屏缩略图未覆盖，可按本索引选用新图。
- 演示好友、共享地点、消息和邀请属于 Demo 状态；配图不代表真实多人服务已上线。拍摄过程没有发送真实消息或启用摄像头。

打开 [图片总览.html](图片总览.html) 可浏览全部配图并点击原图。棋盘格只用于总览展示透明区域，不在 PNG 文件中。
